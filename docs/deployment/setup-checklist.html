Accounts and keys

0/16 done · half a day

Create every account and collect every key before anything is installed. Keep a password manager open: several services show a secret only once.

  1. Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
winget install --id Git.Git -e
winget install --id OpenJS.NodeJS.22 -e
npm install -g pnpm@latest-10
git config --global core.autocrlf false
  2. cd ~\Documents
git clone https://github.com/MinaLouisLeon/integr8-plus.git
cd integr8-plus
pnpm install
  3. ssh-keygen -t ed25519
Get-Content $env:USERPROFILE\.ssh\id_ed25519.pub | Set-Clipboard
  4. $b = New-Object byte[] 24; [Security.Cryptography.RandomNumberGenerator]::Create().GetBytes($b); -join ($b | ForEach-Object { $_.ToString('x2') })
  5. pnpm --silent --filter @integr8/auth keygen | Select-String '^[A-Z_]+=' | ForEach-Object Line | Set-Content -Encoding ascii $env:TEMP\integr8-keys.txt
notepad $env:TEMP\integr8-keys.txt
Remove-Item $env:TEMP\integr8-keys.txt
  6. $k = New-Object byte[] 32; [Security.Cryptography.RandomNumberGenerator]::Create().GetBytes($k); [Convert]::ToBase64String($k)

Apps for each company

0/8 done · 25 min per company

Each company gets desktop installers and a phone app with its own name, icon and colours. One Expo project and one Firebase project serve them all.

Short name with a hyphen? Android turns it into an underscore: al-noor becomes com.integr8.plus.al_noor. A short name starting with a digit gets a c in front.

Start fresh on the machine

0/9 done · 30 min

Deletes every Integr8 container, the database and the images, then starts again from an empty database. Every company, staff account and sign-in on this machine is lost. Other projects on the machine (MyRooms) are not touched.

  1. sudo /opt/integr8/deploy/vps/backup-postgres.sh
ls -lh /home/integr8-backup | tail -3
  2. scp LOGIN-USER@SERVER-IP:/home/integr8-backup/integr8-YYYYMMDD-HHMM.sql.gz .
scp LOGIN-USER@SERVER-IP:/opt/integr8/deploy/.env ./integr8-env-backup
  3. docker ps -a --format 'table {{.Names}}\t{{.Status}}'
  4. cd /opt/integr8
docker compose -f deploy/compose.yml --env-file deploy/.env down -v --rmi all --remove-orphans
docker builder prune -af
  5. docker ps -a --filter name=integr8 -q
docker volume ls --filter name=integr8 -q
docker image ls 'integr8-*' -q
  6. docker stop $(docker ps -q) 2>/dev/null
docker system prune -a --volumes -f
  8. cd /opt/integr8
git checkout main
git pull
grep -E '^(APP_VERSION|API_RELEASE)=' deploy/.env
  9. docker compose -f deploy/compose.yml --env-file deploy/.env up -d --build
docker compose -f deploy/compose.yml --env-file deploy/.env logs -f bootstrap migrate auth api
